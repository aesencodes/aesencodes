# aesen

I have opinions about websites.

They should look good.  
They should feel good.  
They should be fast.  
And they probably shouldn't look like everyone else's.

I like building things from scratch.  
If I can make it myself, I probably will.

Not because it's always the smartest choice.  
Mostly because it's more fun that way.

Also, I have trust issues with UI libraries sometimes.

I spend an unreasonable amount of time looking at award-winning websites and thinking:

**“Damn. I want to know how they did that.”**

Then I try to make it.

Sometimes I nail it.  
Sometimes I spend three hours fighting one animation.  
Sometimes I surrender and pretend it was intentional.  
Sometimes I figure out why I couldn't do it.

Either way, I get better.

**Creative development · Web design · Web strategy**

`React` · `TailwindCSS` · `GSAP` · `Lenis` · `Three.js` · `R3F`

And when things need to happen behind the scenes,  
I can make the backend behave too:

`NestJS` · `PostgreSQL` · `MongoDB` · `DrizzleORM`
